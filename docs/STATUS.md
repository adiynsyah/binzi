## Cara kerja yang sudah berjalan

- Satu kartu = satu sesi Claude Code baru. Prompt pembuka ada di `docs/tasks/README.md` — cukup ganti ID kartu.
- Agent membuat branch, commit, push, dan PR sendiri. Kamu meninjau ("Verifikasi oleh kamu" di kartu + tab "Files changed"), lalu **Squash and merge**.
- PR yang CI-nya merah tidak bisa di-merge: aturan branch `main` mewajibkan PR dengan check `ci` + `e2e` hijau, tanpa bypass admin (sejak 20 Okt — sebelumnya kalimat ini tidak benar, `main` tanpa aturan sama sekali).
- Pertanyaan pilihan dari agent (mis. soal file di luar lingkup): bila ragu, bawa ke Claude chat dulu sebelum menjawab.
- Status pekerjaan dilacak di `STATUS.md` ini. ClickUp tidak dipakai.
- `STATUS.md` masuk ke `main` hanya **di antara PR** (setelah satu PR di-merge, sebelum sesi agent berikutnya). Commit ke `main` saat branch kartu terbuka memicu rebase lokal dan divergensi (kasus PR #53: `ahead 9, behind 8`). Sejak 20 Okt semua docs (STATUS, kartu, PRD) lewat branch `docs/…` + PR — push langsung ke `main` ditolak — dan menunggu `ci` + `e2e` hijau (±5 menit) sebelum Squash and merge. Jangan menambah `paths-ignore` untuk docs di `ci.yml`: check wajib yang tidak pernah berjalan menahan PR selamanya ("Expected — Waiting").
- Perbandingan visual dilakukan di Claude chat: unggah folder screenshot agent (`~/binzi-<kartu>-screenshots/`). Agent tidak bisa melihat screenshot-nya sendiri di lingkungan ini.
- Checklist saat A-07: baca file SQL migrasi sebelum merge (tipe kolom, NOT NULL, foreign key, index) dan cocokkan dengan PRD §11.2–§11.4; tidak ada tabel `certificates`, `consultation_requests`, `course_categories`; satu definisi tabel user (hasil CLI Better Auth + kolom §11.2); seed hanya data sistem dengan nomor WhatsApp dummy, tanpa isi gizi; `db:seed` idempoten.
- Halaman `/dev/ui` hanya hidup di development (404 di preview & production) → verifikasi komponen UI selalu di lokal.
- URL Preview Vercel dilindungi Deployment Protection (SSO): agent tidak bisa membukanya (curl → 302 ke login). Pembukaan Preview selalu oleh kamu, sambil login Vercel.
- Setelah mengubah env di Vercel: redeploy **tanpa build cache**, lalu buka `/masuk` di Production. Status "Ready" tidak membuktikan env benar.
- **PR Dependabot** (cooldown 14 hari sejak C-01, hanya untuk version updates): sebelum merge, bandingkan lockfile per entri (versi + integrity) terhadap basis PR dan cek umur setiap versi baru — cooldown hanya menahan versi paket yang diusulkan, bukan dependensi transitif yang ikut ter-resolve, dan PR security update tidak kena cooldown. PR berbasis `main` lama di-rebase dulu (komentar `@dependabot rebase`) agar CI berjalan di basis terkini. PR yang bertentangan dengan kartu (mis. versi yang dipin kartu chore) ditutup dengan komentar alasan — Dependabot tidak mengusulkan versi itu lagi. Batas bawaan 5 PR terbuka: bila penuh, tab Dependabot (Insights → Dependency graph → tab "Dependabot" di atas isi halaman, bukan di sidebar) bertanda ⚠ "cannot open any more pull requests" — baca pesan job sebelum menyimpulkan konfigurasi rusak.
- **DB lokal (sejak C-05, 28 Okt):** development & uji manual memakai Postgres lokal (`npm run dev:db`), bukan binzi-dev. Setiap PR yang membawa migrasi diikuti `npm run db:migrate:binzi-dev` oleh pemilik (env dari `.env.binzi-dev`) sebelum fiturnya dibuka di Production; pengubahan role di binzi-dev lewat `npm run user:role:binzi-dev`.
