VERIFIKASI

Checklist sebelum selesai

Daftar periksa sebelum sebuah layar dianggap selesai dikoding (§13.4, §8.5). State yang ditebalkan adalah yang paling sering lupa dibuat.

Semua kendalidefault · hover · focus terlihat · disabled · loading
Form (masuk/daftar)kosong · terisi · error per field · error server · terkirim
Player materimemuat · video gagal dimuat · materi tanpa video · selesai
Quizkonfirmasi · berjalan · sisa waktu < 2 menit · auto-save gagal · waktu habis
Hasil quizlulus · belum lulus · dibuka lagi dari Nilai Saya
Dashboard memberpengguna baru (kosong) · pengguna aktif
Daftar & tabelkosong · sebagian · penuh · gagal memuat
Aksesibilitas (WCAG 2.1 AA)
  • Kontras teks ≥ 4,5:1; judul besar ≥ 3:1.
  • Ukuran teks dasar 16px — persona P3 berusia 45+.
  • Seluruh alur bisa diselesaikan dengan keyboard; urutan fokus mengikuti urutan baca.
  • Warna tidak pernah jadi satu-satunya penanda — selalu ada teks atau ikon.
Yang tidak terlihat dari UI (§12.6)
  • Respons API soal quiz tidak boleh memuat is_correct maupun pembahasan.
  • Attempt kedua ditolak server (409), bukan hanya disembunyikan di UI.
  • Setiap query berbasis ID menyertakan kepemilikan user (anti-IDOR).
  • Timer dihitung server; waktu klien hanya tampilan.
