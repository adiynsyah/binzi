## Tujuan
Kerangka menjadi dasar naskah, video, dan soal (§13.2).

## Langkah
1. Untuk setiap kursus: judul, level, target peserta, tujuan belajar, daftar materi (judul + 1 kalimat isi), perkiraan durasi.
2. Pakai judul asli yang panjangnya realistis — judul ini juga dipakai untuk menguji tata letak (§13.5).
3. Tandai materi 1 tiap kursus sebagai **preview gratis** (CRS-09).
4. Minta ahli gizi meninjau kerangka sebelum naskah ditulis.
